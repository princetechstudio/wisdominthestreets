# ⚡ Quick Reference — Deploy in 5 Minutes

## 🚀 Deploy to Vercel (Recommended)

```
1. Push to GitHub
   git add . && git commit -m "Launch" && git push

2. Go to: https://vercel.com/new
3. Import repository
4. Click "Deploy"
5. ✅ Live! (gets URL like https://xxx.vercel.app)

6. (Optional) Connect custom domain:
   - Go to Vercel Dashboard → Settings → Domains
   - Add your domain
   - Update DNS records
```

## 🚀 Deploy to Netlify

```
1. Push to GitHub
   git push origin main

2. Go to: https://app.netlify.com/start
3. Connect GitHub
4. Click "Deploy Site"
5. ✅ Live! (gets URL like https://xxx.netlify.app)

6. (Optional) Add custom domain in Domain settings
```
